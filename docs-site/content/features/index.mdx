Cette page documente les features importantes de `circular.moda`.

Chaque feature garde la meme structure :

- une **version simple**, pour comprendre rapidement ce que fait la feature ;
- une **version detaillee**, avec des blocs repliables pour ne pas surcharger la
  page et le sommaire Nextra.

## Structure d'une page feature

Chaque sous-page garde la meme logique :

- une version simple pour comprendre rapidement le comportement ;
- une version detaillee avec les services, tables, routes, fichiers, variables et tests utiles.

Quand une feature change, mettre a jour sa sous-page dans la meme session de travail.
