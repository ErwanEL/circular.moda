# Publication produits Instagram

## Version simple

La feature permet de publier des produits Supabase sur le compte Instagram
professionnel `circular_punto_moda` via l'Instagram Graph API.

Le site selectionne des produits eligibles, cree une caption, publie l'image sur
Instagram, puis enregistre le resultat dans Supabase pour eviter les doublons.

Le lien cliquable utilise dans la bio doit etre :

```text
https://circular.moda/instagram
```

Les URLs dans les captions Instagram restent du texte non cliquable. Le lien
produit est donc place sur sa propre ligne pour faciliter la copie.

```env
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
CRON_SECRET=
NEXT_PUBLIC_SITE_URL=https://circular.moda
INSTAGRAM_ACCESS_TOKEN=
INSTAGRAM_IG_USER_ID=17841430654232393
INSTAGRAM_GRAPH_API_VERSION=v26.0
INSTAGRAM_PUBLISHING_ENABLED=true
```

Ne jamais documenter les valeurs secretes.

Pour production, utiliser le Page Access Token de `Circular.moda` obtenu apres
echange d'un User Access Token court contre un User Access Token long-lived.

## Routes

Routes ajoutees :

- `GET /api/cron/publish-instagram-products`
  - dry-run par defaut ;
  - publication batch avec `publish=1` si `INSTAGRAM_PUBLISHING_ENABLED=true`.
- `POST /api/admin/instagram/publish-product`
  - preview/publish d'un produit precis ;
  - publication reelle seulement avec `confirm: "PUBLISH_TO_INSTAGRAM"`.
- `GET /api/instagram/product-image/[id]`
  - proxy JPEG public pour Meta.
- `GET /instagram`
  - page publique pour le lien en bio.

Toutes les routes internes de publication demandent :

```http
Authorization: Bearer ${CRON_SECRET}
```

## Commandes utiles

Dry-run :

```bash
curl -H "Authorization: Bearer $CRON_SECRET" \
  "http://localhost:3000/api/cron/publish-instagram-products?limit=3&checkQuota=1"
```

Preview produit :

```bash
curl -X POST "http://localhost:3000/api/admin/instagram/publish-product" \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"productId":1452,"imageMode":"source"}'
```

Publication reelle :

```bash
curl -X POST "http://localhost:3000/api/admin/instagram/publish-product" \
  -H "Authorization: Bearer $CRON_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"productId":1452,"imageMode":"source","confirm":"PUBLISH_TO_INSTAGRAM"}'
```
