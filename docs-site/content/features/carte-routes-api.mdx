# Carte des routes API

## Version simple

Cette page liste les routes API du site, leur role, leur niveau de protection et
les fichiers a ouvrir.

Elle sert de point d'entree rapide pour un humain ou un agent IA avant de
modifier une feature qui touche aux donnees, a Supabase, a Brevo, a OpenAI ou
au cache.

Avant un refactoring API :

1. Identifier les routes touchees dans cette page.
2. Lire la page feature correspondante.
3. Verifier auth/secrets/cache.
4. Lancer au minimum :

```bash
npm run build
```
