# Operations

Cette section regroupe les procedures qui doivent rester faciles a rejouer :
synchronisation de donnees, rotation des articles mis en avant, verification Git
et futurs runbooks.

## Procedures disponibles

- `Featured products` : preparer et appliquer un nouveau batch de produits mis
  en avant.
- `Source control` : verifier que le depot local est bien synchronise avec le
  remote GitHub.
