# Documentation interne circular.moda

Cette documentation est locale pour l'instant. Elle sert a garder les decisions,
les commandes utiles et les procedures operationnelles proches du code.

## Objectif

- Retrouver rapidement comment lancer le projet, synchroniser les donnees et
  verifier les changements.
- Documenter les features au fur et a mesure, directement dans le meme depot.
- Documenter le role des agents IA qui travaillent sur le projet.
- Servir de reference commune aux developpeurs humains et aux agents IA avant
  de modifier ou refactorer une partie du code.
- Garder une base simple a heberger plus tard comme projet Vercel separe si on
  decide de l'ouvrir avec une protection d'acces.

## Usage humain et agents IA

Avant de travailler sur une feature, commencer par la page correspondante dans
`Features`. La version simple donne le comportement produit ; la version
detaillee donne les services, tables, routes, fichiers, variables
d'environnement et tests a verifier.

Quand une feature change, mettre a jour sa documentation dans le meme commit ou
dans la meme session de travail. L'objectif est que la prochaine personne, ou le
prochain agent IA, puisse comprendre le contexte avant de toucher au code.

## Structure

- `docs-site/` : app Nextra locale.
- `docs-site/content/` : pages Markdown/MDX affichees dans la doc.
- `docs/` : notes historiques et fichiers operationnels deja presents dans le
  depot.
- `docs/imports/` : documents et assets bruts importes depuis une machine
  developpeur.
- `scripts/` : scripts utilitaires pour Supabase, featured products et donnees.
