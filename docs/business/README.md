# Suivi business

Ce dossier garde l'historique des discussions business autour de circular.moda :
positionnement, parcours utilisateur, monetisation, hypotheses a tester et
decisions prises.

## Format conseille

Chaque point important peut etre ajoute sous forme de note datee :

```text
YYYY-MM-DD-sujet.md
```

Une note doit idealement contenir :

- le contexte de la discussion ;
- les constats utilisateur ou marche ;
- les hypotheses business ;
- les decisions prises ;
- les prochaines actions.
